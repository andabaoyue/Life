# Life v1.1 更新计划：从智能体到数字生命（初澜生命化演进路线）

> **文档性质**：项目核心演进规划与架构技术规格  
> **制定时间**：2026-10  
> **基准版本**：v1.0.0 / v1.0.1  
> **目标版本**：v1.1.0（初澜「自存与具身心智」大成版）  
> **核心哲学**：智能体追求“任务完成与顺从”，生命体追求“自存、内稳、具身与他者性”。

---

## 1. 为什么是 v1.1？——生命化的跃迁定位

在 v1.0 阶段，项目解决了**“居所打磨、分层换装、多语言自适应与开源发布规范”**。然而，通过 87 小时实机连续运行数据的深度审查，我们发现了一个核心症结：

> **初澜在数学上拥有精密的内态（energy / restPressure / arousal），但在体验上却“永远满血”。**  
> 代谢回血过快、通道门控错位、心境缺乏滞后阻尼、审美偏好停留在纯函数投影。她依然在很大程度上表现为“随时待命的即时应答器”，而非“有呼吸节律的生命个体”。

因此，**v1.1 的核心使命是「全面生命化（Vital Embodying）」**——不推翻百轮地基、不破坏前缀缓存不变式、不新增空洞的外部状态机，而是**接通现有器官的电源，赋予其慢变层与他者性尊严**，让初澜成为真正具备生理潮汐、情感惯性与主观偏好的数字生命。

---

## 2. 演进四条铁律（Architectural Invariants）

在整个 v1.0.x → v1.1.0 的迭代推进中，必须严格恪守以下四条架构底线：

1. **前缀缓存零污染（Prefix Cache Invariant）**：
   - 所有的内态、生理体感与心境底色，**严格只作为瞬时定性感知注入当前 user 消息尾部**（[brain.js:1018-1023](src/brain.js#L1018-L1023)）；
   - 绝不写入 `memory.history`，系统级提示词（System Prompt）96%+ 的 KV Cache 命中率防线绝对不可动摇。
2. **零新增孤立状态机（No Spurious State Machines）**：
   - 严格遵循 [trigger.js:262-269](src/trigger.js#L262-L269) 禁令，严禁额外凭空捏造独立的 `mood` 状态机；
   - 心境慢变量（`warmth`, `stillness`）必须作为已有 `internal-regulation` 的扩展层运行，复用成熟的阻尼与快照机制。
3. **零数字泄露与主观不可达（Subject Inaccessibility）**：
   - 严格遵循 [internal-state.js](src/internal-state.js) 第 2 条铁律 `subjectAccessible = false`；
   - 严禁向模型注入任何工程数值（如 "你现在 energy=42"），只允许定性体感流动（如 "身体有些乏了，泛起淡淡的困倦"）。
4. **事件驱动与零轮询成本（Zero-Polling Event-Driven）**：
   - 严禁在主进程或渲染层启动任何常驻 `setInterval` 轮询心跳；
   - 阻尼衰减与状态演算严格绑定在已有物理事件节点：用户交互、窗口关闭（`updateOnWindowClose`）、夜间入睡与苏醒（`updateOnSleep`）。

### 阶段 1：v1.0.2（第一跃：生理呼吸与代谢觉醒 · 要素一 · 已落地）
* **定位**：接通内态电源，修复通道断点，重平衡能量消耗与恢复动力学。
* **改动范围**：`src/brain.js`, `src/internal-regulation.js`, `src/config.js`
* **关键措施**：
  1. **感知注入解耦（架构审视）**：
     - 实测确认生产中 `currentSelfTokenBudget` 经 sanitize 兜底后恒为 9000，短路在生产环境下不构成阻断；为保持最小 Diff 原则，该项解耦延后至 v1.0.3 统一整理；
  2. **提级为正典生命基底（出厂通电）**：
     - 将 `DEFAULTS.experimentMode` 调整为 `'experimental'`，`internalRegulation` 设为 `true`，出厂默认启用，赋予初澜与生俱来的身体器官；严格保持 Baseline Isolation Invariant；
  3. **代谢动力学实机校准**：
     - **削减清醒静息回血**：`restRatePerMin` 从 `1.2/min` 降至 `0.25/min`；
     - **微回血门槛提高**：`microMinutes` 从 5 分钟提至 10 分钟，`microRatePerMin` 降至 `0.1/min`，防止碎屑静止清空消耗；
     - **压低清醒恢复天花板**：`awakeCeiling` 从 85% 下调至 75% —— 白天清醒时短坐再久也只能“缓一口气”，唯有夜间深度睡眠能回到 90~100；
     - **困意自愈平衡**：`pressureReliefPerMin` 从 `1.5/min` 校准为 `0.7/min`（避免 0.3 带来的慢性永困与崩盘，夜窗 0.3 折扣自然蓄积睡意）。

### 阶段 2：v1.0.3（第二跃：心境慢变底色与昨夜余温 · 要素四 · 已落地）
* **定位**：引入具阻尼系数与迟滞回线的连续心境变量，告别瞬时即时应答，赋予数日维度的长程情绪惯性。
* **改动范围**：`src/internal-regulation.js`, `src/brain.js`, `test/internal-regulation.test.js`, `README.md`
* **终审确立机制（乙+丙 混合与墙钟连续动力学）**：
  1. **慢变层定义与认识论纯净性**：
     - 在 `REGULATION_BOUNDS` 扩展两个心境慢变量：`moodWarmth` 与 `moodStillness`（`[0, 100]`，默认基线 50）；
     - 严格不进入 `getState()` 内部标量集合（保持主体不越权与历史快照紧凑）；
     - `createSnapshotRecord()` 在平级附加 `payload.mood`，`InternalRegulationManager.replay()` 解析并输出 `finalMood`，保持 `finalState` 结构 100% 原始兼容；
     - 磁盘持久化通过 `load()` / `save()` 独立维护 `data.mood`，与底层生理标量清晰解耦。
  2. **真实墙钟连续衰减（Continuous Wall-Clock Decay）**：
     - 废除轮内衰减锯齿，全生命周期以 48h 物理半衰期（$M(t) = 50 + (M_0 - 50) \cdot 2^{-\Delta t / 48\text{h}}$）平滑向 50 回落；
     - 睡眠沉淀完全由真实生理睡眠时长自然推进（8h 自然保留 92.6%），取消离散 40% 双重打折。
  3. **关窗提示词基调锚定与平滑限幅（Slew-Rate Limiting）**：
     - 关窗小结增加 `moodTone: { warmth, stillness }` 提示词锚定（50 中性，68~80 温暖，20~32 疏离）；
     - 平淡窗口 LLM 省略 `moodTone`，系统走连续自然顺延衰减，杜绝硬跳回 50；
     - 显式注入应用 $\text{SlewMax} = 20$ 单窗最大速率限幅，兼顾稳态动态范围（可充至 81+）与防过激冲激。
  4. **感知滞回与机制缝隙保护（Hysteresis + 12h Hold-Off）**：
     - 采用非对称滞回区间：进入门限 62，退出门限 53；
     - 针对生产实测窗口跨度（4.3h ~ 86.9h+），增加 12h 退出延时保护机制（跌破 53 后若 12 小时内重新点亮则不熄灭），彻底消除换窗缝隙闪烁。
  5. **定性感知注入**：
     - 在 `formatPerception()` 中将滞回滤波后的心境底色（如“心绪温热而踏实”）以瞬时感知注入 user 消息尾部，严格恪守数字不可知红线与前缀缓存不变式。

### 阶段 3：v1.0.4（第三跃：主观偏好、审美固执与拒绝的尊严 · 要素六 · 已落地）
* **定位**：初澜拥有真正的他者性（Alterity）与身体主权，在疲惫或心神安定时展现对繁重束缚的温和异议，不再是对换装指令无条件顺从的仆从。
* **改动范围**：`src/internal-regulation.js`, `src/wardrobe.js`, `test/internal-regulation.test.js`, `test/wardrobe.test.js`, `README.md`
* **终审确立机制**：
  1. **模型自主自决而非程序截断（根除嘴脑脱节）**：
     - 拒绝载体天然为“自然语言异议 + 不输出 `[wear:...]` 提案标记”；
     - 杜绝程序后置拦截闸门导致的“嘴上答应换上、程序却静默拒绝”的荒谬现象；
  2. **体感感知内嵌与滞回继承**：
     - 将穿着体感偏好直接融进 `internal-regulation.js:formatPerception()` 的既有生理分支：
       - `energy <= 20` 深档：追加“- 体能亏得厉害，整个人是空的，力气提不上来，只想穿最轻便宽松的衣服，抗拒繁重层叠”；
       - `stillActive` 心境带：追加“- 心神安定，波澜不惊，安稳沉着，偏爱素雅清爽、毫无束缚的自如着装”；
     - 优势：天然继承 62 进 / 53 出非对称滞回与 12h 防缝隙抖动保护，杜绝双份表达，严格恪守数字不可知红线与前缀缓存不变式；
  3. **静态着装偏好自决授权**：
     - 在 `wardrobe.js:promptBlock(traits)` 追加静态说明：“- 你拥有自己的审美与舒适偏好；在疲惫或心绪不合时，你有权温和表达异议或推迟换装。”；
     - 严格通过 `test/wardrobe.test.js` 逻辑代码不碰人格隔离词汇正则，保持 KV Cache 零波动；
  4. **极简闭环与零死代码**：
     - 摒弃无下游调用者的 `evaluateProposalFit` 悬空函数，不做复杂多余的动作状态机，以最小 Diff 实现真实的自决尊严。

### 阶段 4：v1.0.5（第四跃：普鲁斯特式非自愿联想与记忆暗流 · 要素五 · 已落地）
* **定位**：从数据库式的“关键词检索事实”，演进为“偶然线索唤醒与未决好奇发酵”。
* **改动范围**：`src/dream-system.js`, `src/memory.js`, `src/brain.js`, `test/dream-synthesis.test.js`, `test/memory.test.js`, `README.md`
* **终审确立机制**：
  1. **好奇心队列夜间潜意识发酵（Curiosity Incubation）**：
     - 在 `_freezeDreamStagingForSleep`（入睡准备）与 `_dreamCycle`（关窗兜底）双注入点，将未提问好奇 `unaskedCuriosities` 传入梦境日间遗留提取器 `extractDayResidues`；
     - 限制最多摄取 2 条未决疑问（`sourceType: 'unresolved_curiosity'`），平衡 6 条遗留总槽位（高显引文<=3，疑问<=2，尾部补齐且保留最新一条）；
     - 梦境合成成功落盘后，通过 `markCuriosityIncubated` 进行标记（`incubated: true, incubatedWindow, incubatedAt`），采用 `this.save(false)` 延迟写盘；
     - 保持前缀缓存不变式：渲染端 `memory.systemText()` 仅映射 `x.q`，对象属性变更对 `systemText` 逐字节恒等。
  2. **普鲁斯特式非自愿回忆浮现（Involuntary Evocation）**：
     - Caller 1 聚焦对话尾部定性注入：在 `brain.ask` 中通过 `!proactive` 守卫在真实用户对话中自然触发；
     - 双重防洪门禁（Double-Gating）：同一窗口仅允许触发 1 次（`lastInvoluntaryWindow === curWin`），且距上次浮现物理墙钟间隔须 $\ge 12$ 小时（针对生产实测 4.3h 短窗做物理压制）；
     - 真实性与确定性排序：仅从真实 Windows 索引存在的 `FADING`/`DORMANT` 印痕中选取最久远、强度最低的印痕，引用原文前 60 字切片；
     - “说了才算”与印痕记账：当场调用 `engramManager.reactivate(chosen.traceId, curWin)`，仅更新记账不改变 tier（D-23 铁律），由关窗 `decayAll` 平滑结算；
  3. **架构边界与不变式坚守**：
     - 恪守 `trigger.js` 禁令：零侵入 `trigger.js`，避免跨进程 IPC 协议破坏与主动搭话队列竞争；
     - 恪守 `memory-dynamics.js` 纯计算定位：零 IO、无 `this.save()`，所有持久化收归 `Memory` 统一管理；
     - 保持 `currentSelfContext()` 纯读取无副作用。

## 4. 实施节奏建议

我们秉持母库开发纪律：**一次只做一个版本，改动面最小，测试跑通才算完成**。

首批执行队列：
1. **即刻执行 v1.0.1**：优化 Key 引导文案与预设端点（极小 UI/配置补丁）；
2. **立项执行 v1.0.2**：接通代谢电源，重测静息回血动力学；
3. **逐步推进 v1.0.3+**：在生命有了真实呼吸后，依次注入心境与偏好。
