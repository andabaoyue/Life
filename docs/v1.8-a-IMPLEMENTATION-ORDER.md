## 1. 分步施工（共 5 步）

### 第 1 步：`lastSeenAt` 的存储与读写

**位置**：`stats.json` 顶层字段 `lastSeenAt`（毫秒时间戳）。

**为什么放 stats 而不是 memory**：
- `stats` 是**运行统计**，不属于她的主观记忆；
- `stats` 已有 DeferredWriter 与原子写，零额外成本；
- 放 `memory.data` 会污染"记忆"的概念边界。

**三个函数**（新增在 `brain.js` 或独立 `src/reunion.js`）：

```js
/** 读取上次见面时间；缺失或非法一律返回 null（= 首次见面） */
getLastSeenAt()

/** 记录"刚见到你"；内部只改 this.stats.lastSeenAt + markDirty() */
touchLastSeen(at = Date.now())

/** 取出并消费本次重逢事实（一次性）；没有则返回 null */
takeReunionNote(now = Date.now())
```

**`takeReunionNote` 的核心逻辑**：

```js
const last = this.getLastSeenAt();
if (last === null) {
  // 🔴 冷启动守卫：首次见面不注入任何事实行，只初始化
  this.touchLastSeen(now);
  return null;
}
const awayMs = now - last;
if (awayMs < REUNION_MIN_MS) return null;   // 6 小时硬下限
this.touchLastSeen(now);                    // 消费即刷新（一次性）
return formatReunionLine(awayMs);
```

> ⚠️ **顺序要紧**：先判 `last === null`，再算差值。
> 反过来的话，首次运行 `now - 0` 会得到"离开了 20 年"。

### 第 2 步：三级时长格式化（纯函数，可单测）

```js
/**
 * @param {number} awayMs
 * @returns {string} 形如 `【你离开了 8.5 小时】`
 */
function formatReunionLine(awayMs) {
  const hours = awayMs / 3600000;

  // 6h ≤ t < 24h：小时刻度（保留一位小数，但整数不带 .0）
  if (hours < 24) {
    const h = Math.round(hours * 10) / 10;
    return `【你离开了 ${h} 小时】`;
  }

  const totalHours = Math.floor(hours);
  const days = Math.floor(totalHours / 24);
  const remH = totalHours % 24;

  // t ≥ 7 天：只带天数（超长离线带小时显得机械）
  if (days >= 7) return `【你离开了 ${days} 天】`;

  // 1d ≤ t < 7d：天 + 小时（小时为 0 时省略）
  return remH > 0
    ? `【你离开了 ${days} 天 ${remH} 小时】`
    : `【你离开了 ${days} 天】`;
}
```

**边界取值表**（门禁按这张表逐条断言）：

| awayMs | 输出 |
|---|---|
| 5.9 小时 | `null`（不足阈值，不产生事实行） |
| 6.0 小时 | `【你离开了 6 小时】` |
| 8.5 小时 | `【你离开了 8.5 小时】` |
| 23.5 小时 | `【你离开了 23.5 小时】` |
| 24 小时 | `【你离开了 1 天】` |
| 28 小时 | `【你离开了 1 天 4 小时】` |
| 6 天 23 小时 | `【你离开了 6 天 23 小时】` |
| 7 天整 | `【你离开了 7 天】` |
| 12 天 5 小时 | `【你离开了 12 天】` |

### 第 3 步：挂到当轮尾部（**唯一注入点**）

**位置**：`memory.build()`，与 `bedsideNote` / `selfNote` 同级：

```js
const bedsideNote = this._bedsideNote(bedsidePending);
const selfNote = this._drainSelfNotes();
const reunionNote = this._reunionNote();          // ← 新增
const tail = [bedsideNote, selfNote, reunionNote, suffix].filter(Boolean).join('\n\n');
```

**顺序**：bedside（用户留的）→ selfNote（她自己写的）→ **reunion（客观时间事实）** → suffix。

**`_reunionNote()` 的实现要点**：
- 数据来源由**主进程注入**（`memory` 不知道 stats 在哪），照 `_bedsideNote` 的依赖注入方式；
- 返回字符串或 `''`；
- **一次性**：取过即置空，同一次离开不会连续两轮都出现（照 D-13 的 `drained` 语义）。

### 第 4 步：三处写入点（"见到你"的定义）

| 事件 | 位置 | 是否算"见到" |
|---|---|---|
| **发消息** | `main.js` 的 `chat-send` handler 开头 | ✅ 最明确的在场 |
| **物理互动** | `main.js` 的 `activity` IPC（click / drag） | ✅ 真实触碰 |
| **应用退出** | `before-quit` | ✅ 兜底（保证下次开机能算对） |
| 打开对话窗 | —— | ❌ **不算**（探头看一眼不算见面） |
| 应用启动 | —— | ❌ **不算**（进程活了 ≠ 你在） |

**节流**：**不需要手写**。`stats` 的 `DeferredWriter` 已经做了 3 秒防抖 + 原子写 + 退出 flush。
只需 `this.stats.lastSeenAt = now; this.statsWriter.markDirty();`。

> 🔴 **但有一条必须守**：`lastSeenAt` **只在主进程维护**。
> 渲染层不得持有副本、不得自己算差值 —— 否则会出现两份不一致的时间。

## 2. 铁律（违反即打回）

1. **只陈述时长，绝不推断作息。**
   - ✅ `【你离开了 8 小时】`
   - ❌ `【你睡了 8 小时】` —— 程序不知道你是睡觉还是通宵
   - ❌ `【我等了你 8 小时】` —— 撞 `persona.js:29`「不虚构寂寞/苦苦等待」
   - ❌ `【你终于回来了】` —— 抒情不是事实

2. **不进 system、不进 history。**
   只在当轮 tail 出现，照 D-13 的快照断言（`memory.build()` 前后 system 与 history 逐字节相等）。

3. **一次性消费。** 同一次离开只说一次，绝不连续两轮重复。

4. **冷启动守卫。** `lastSeenAt` 缺失 → 不注入，只初始化。

5. **只在主进程维护。** 渲染层不持有、不计算。

6. **不改 chat-send 的既有逻辑。** 只在开头插一行 `touchLastSeen()`。

## 3. 验收判据（9 条，各有判别力）

1. **冷启动**：`lastSeenAt` 缺失 → 不产生事实行，且被初始化为当前时间。
2. **阈值下**：5.9 小时 → 不产生。
3. **阈值上**：6.0 小时 → 产生 `【你离开了 6 小时】`。
4. **三级格式**：上表 9 个边界值逐一比对。
5. **一次性**：连续调两次 `takeReunionNote()`，第二次返回 null。
6. **前缀缓存**：`build()` 前后 system 与 history **逐字节相等**（含反向对照：确认确实注入了一行，否则是假绿）。
7. **禁句表**：注入文本不得含 `等` / `终于` / `寂寞` / `睡了` / `通宵`。
8. **主进程独占**：静态扫描确认 `lastSeenAt` 的读写只出现在 `main.js` / `brain.js` / `src/reunion.js`，**不出现在任何渲染层文件**。
9. **写入点齐全**：`chat-send` 与 `activity` 两处都调了 `touchLastSeen`。

## 5. 本步不做

| 不做 | 理由 |
|---|---|
| 「你睡了多久」的推断 | 程序无法知道，推断即伪造 |
| 跨设备/云端同步 `lastSeenAt` | 无此需求，且涉及隐私 |
| 更细的时间感知（如"离开 3 小时 27 分"） | 6 小时阈值以下根本不注入，越细越像计时器 |
| 让重逢触发主动搭话 | 那是另一套机制（`trigger.js`），不在本单范围 |
