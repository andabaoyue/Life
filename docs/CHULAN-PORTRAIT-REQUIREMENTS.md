## 一、立绘体系定位与设计宗旨

初澜的美术资产体系采用**双层正典（Dual-Canon）**架构：

```
                    ┌──────────────────────────────────────────────┐
                    │               初澜角色美术体系                │
                    └──────────────────────┬───────────────────────┘
                                           │
                 ┌─────────────────────────┴─────────────────────────┐
                 ▼                                                   ▼
   【桌面具身 · 活体正典】                             【档案鉴赏 · 记忆正典】
   · 64×80 原生 Q 版点阵精灵                          · 760×1000 高精写实半身/全身原画
   · 2~2.5 头身娇羞依赖体型                           · 成熟细腻画风，收录于「画册/回忆系统」
   · 桌面漫步、呼吸、受戳、熟睡交互                   · 彻底与桌面实时交互窗口解耦
   · 本规范的核心约束对象                             · 仅作设计风格与色彩设定的参考母本
```

### 1.1 核心人设与气质基调
- **角色性格**：内向沉静、娇羞细腻、依恋陪伴、轻微笨拙憨态（呆萌小内八）。
- **视觉风格**：银白清冷长发与冰蓝渐变微卷发尾，搭配黑白哥特机能/蕾丝清凉服饰，整体呈现冷色调中的温润少女感。
- **体态语言**：小内八站姿、圆润小手在身前轻触、大眼灵动微羞。

## 二、画布与物理渲染规格

| 属性项 | 规格标准 | 说明与强制要求 |
|---|---|---|
| **原生设计画布** | **64 像素（宽）× 80 像素（高）** | 像素原生点阵网格，所有帧、动作、部件均必须在此时空坐标系下绘制。 |
| **重心与脚底基线** | **脚底水平线固定于 $y = 74$**，**水平轴线居中于 $x = 32.0$** | 确保换帧、动作切换与地面对齐时角色不发生垂直/水平跳闪或沉浮。 |
| **头顶安全净空** | **顶部预留 $10 \sim 12$ 像素**（最高处呆毛尖止于 $y \ge 5$） | 严禁顶格贴边，防止桌宠窗口顶部截断呆毛及遮挡对话气泡。 |
| **显示放大倍率** | **1x 原生（64px 掌心宠）或整数倍（128px / 256px）** | 渲染必须使用 `image-rendering: pixelated`（最近邻 Nearest-Neighbor 插值）。**严禁小数倍缩放（如 1.5x / 96px）**，严禁双线性模糊。 |
| **桌面视口窗口** | **256 × 320**（Electron 紧凑窗口） | 窗口透明无边框，立绘位于视口底部居中，彻底消除多余透明边缘吃鼠标的问题。 |
| **通道格式** | **32-bit RGBA（纯净 1-bit 二值化 Alpha）** | **透明度必须非 0 即 255**。透明背景处 $\alpha = 0$，角色像素 $\alpha = 255$。**严禁半透明毛边（Alpha $\in [1, 254]$）**，杜绝透明窗口下的黑斑或光晕。 |
| **调色盘色彩预算** | **整套立绘 $\le 32$ 色**（标准色盘：`Chulan 24`） | 色彩严格离散聚类，避免过度丰富导致像素噪点散乱。 |

## 三、初澜正典视觉特征不变式（八大核心要素）

任何初澜立绘资产（无论何种动作、服装、表情），以下八大视觉特征**具有绝对守恒性**，不可省略或形变：

### 1. 水灵双高光眼眸（Gaze & Eyes）
- **眼瞳色彩**：上层深海蓝（`#203250` ~ `#324C78`）$\to$ 下层清透冰蓝（`#6EA5E1` ~ `#A0D0F5`）的逐阶过渡。
- **标志性双白高光**：
  - **主高光**：位于眼瞳左上方（2px 竖点或 $2\times 1$ 块），纯白 `#FFFFFF`；
  - **副高光**：位于眼瞳右下方（1px 微光点），纯白 `#FFFFFF`；
  - 形成波光粼粼的水润依赖感。

### 2. 泪痣专属签名（Canonical Tear Mole）
- **位置**：观众视角右眼（角色本人左眼）的正下方脸颊粉晕边缘。
- **尺寸与色彩**：**精准且唯一的 1 颗像素（1px）**，取色深褐紫（`#40303A` / `#44343E`）。
- **间距要求**：**必须与下眼眶轮廓线保持至少 1~2 像素的亮肤色净空**，严禁贴死眼线（防止缩小或远看时与睫毛粘连被误判为眼圈杂色）。

### 3. 头顶微翘呆毛（Ahoge）
- **造型**：从头顶发旋拱起，向左上方优雅微翘，尖端带有微卷弧度。
- **根部结构**：**呆毛与头顶头皮连接处必须保持 2 像素宽**，衔接自然扎实，杜绝 1px 细线带来的“悬浮插线”感。
- **动画戏眼**：待机时 1px 弹性摆动，受戳（Poke）时具备弹簧式压缩回弹。

### 4. 冰蓝发尾三阶色阶跳（3-Step Ice-Blue Gradient）
- **发簇色彩层级**：
  - 阶 0（银白主发）：`#F2F5FC` / `#E2E8F4`（带有微弱蓝紫冷调的高亮发丝）；
  - 阶 1（柔淡冰蓝）：`#A5C2E6`（中段过渡发簇）；
  - 阶 2（清透冰蓝）：`#6EA5E1`（发稍微卷处）；
  - 阶 3（发梢深冰蓝）：`#4178B4`（外轮廓发卷收束阴影）。
- **阶梯感铁律**：采用纯正像素点阵的分块色阶跳跃（Cluster Stepping），严禁模糊渐变滤镜。

### 5. 蓬松双侧瀑布长发（Twin Waterfall Hair）
- **外轮廓与负空间**：左右两侧大波浪长发自然倾泻至大腿侧下方，发丝与纤细躯干之间保持清晰通透的空气负空间。
- **边缘柔化（AA）**：外侧转折处配置 1~2 颗次冷色像素缓冲阶梯锯齿，体现发丝柔顺垂坠感。

### 6. 小内八字萌系站姿（Pigeon-Toed Stance）
- **足部造型**：双脚脚尖微向内扣，脚弓内收，鞋尖相对（小内八角度）。
- **站立稳固性**：脚底切面紧贴基线 $y=74$，形成稳固着地的娇憨站姿。

### 7. 娇羞圆润小臂与小手（Chibi Hands）
- **比例与动态**：微缩幼态手臂，小肉手在身前相碰或自然垂于大腿两侧，拒绝张牙舞爪或僵硬直棍状。

### 8. 标志性服饰结构（Gothic Mech & Lace）
- **经典服装配置**：
  - 落肩白色微翘短披肩/抹胸（白色质感带蓝灰阴影）；
  - 胸前标志性纯黑蕾丝蝴蝶结，中心镶嵌冰蓝水滴宝石；
  - 颈部深冷灰项圈底带，与胸前黑色蝴蝶结形成明暗阶层；
  - 高腰短裙/短裤，搭配纯白过膝长袜或半透明袜圈。

## 四、审美精修准则（黄金细节技巧）

针对过往绘制迭代中总结的人眼审美关键点，必须严格落实以下八项精修标准：

```
                ┌──────────────────────────────────────────────┐
                │             八项审美细节落地准则              │
                └──────────────────────┬───────────────────────┘
         ┌─────────────────────────────┼─────────────────────────────┐
         ▼                             ▼                             ▼
   【眼睛与表情】                 【发型与外轮廓】               【身形与服饰】
 · 睫毛阴影弧度压实            · 呆毛根部 2px 扎实连接         · 腿部大腿圆润/膝盖微收
 · 泪痣保留 1~2px 亮肤色间距   · 瀑布发边缘次冷色 AA 缓冲      · 膝关节淡粉肉感微光点
 · 脸颊对称 2~3px 暖粉腮红     · 杜绝塑料方块头盔发型          · 项圈深冷灰与蝴蝶结分层
 · 小巧微樱粉唇点                                              · 抹胸上缘冷蓝灰立体阴影
```

### 4.1 眼睛与面部表情
1. **眼神压实度**：上眼眶/上睫毛线必须加厚并具备自然微弧（深冷褐黑），形成眼睑下落阴影，压住眼球上方，杜绝平直一字线（杜绝死鱼眼与死瞪感）。
2. **脸颊微晕**：在双眼外下侧点缀 $2\sim 3$ 颗淡粉腮红（`#F2A8B8` / `#E890A0`），衬托 porcelain 瓷白肤色的温润感。
3. **嘴部微态**：嘴部保持 1~2 像素樱粉色微点，置于下巴弧度上方，严禁拉成长方形黑条或粗厚方块唇。

### 4.2 发丝动态与外轮廓
1. **呆毛扎实度**：发根与头顶接触点为 2px 结构，向上延伸过渡为微弯曲线，尖端 1px 回卷。
2. **长发抗锯齿缓冲**：瀑布发外轮廓不可呈现等距机械阶梯，在阶梯落差处必须引入中间色（如发色高光与阴影之间的中间蓝阶）做 1 颗像素的平滑抗锯齿（Anti-Aliasing）。

### 4.3 腿部线条与形体起伏
1. **去直筒化弧度**：
   - 大腿根部至大腿中段外侧饱满微凸，展现健康婴儿肥肉感；
   - 膝盖关节处轻微向内收缩 1 像素，打破上下等宽的方柱感；
   - 小腿向下平滑收束至纤细脚踝，再自然过渡至微内扣的小脚尖。
2. **膝盖红晕高光**：在左右膝盖骨上方偏内侧各点 1 颗浅粉/暖肉色像素（`#F8C8C0`），能瞬间点亮下半身的立体感与幼态胶原蛋白感。

### 4.4 衣饰层次与阴影立体感
1. **项圈与领结分层**：
   - 颈部项圈带选用冷调深灰（`#3A3E48`）；
   - 胸前蝴蝶结选用纯黑/曜石黑（`#1A1820`），并在打结处点缀 1 颗浅灰高光点；
   - 杜绝项圈与蝴蝶结黑作一团失去立体纵深。
2. **抹胸蕾丝立体边缘**：
   - 纯白布料边缘若直接贴紧瓷白皮肤，容易失去轮廓边界；
   - 在抹胸/内衣上缘贴近皮肤一侧，铺设 1 像素极淡冷蓝灰/冷紫阴影像素（`#D0D8E8`），使衣服边缘形成浮凸立体感。

## 五、动作序列与 SpriteSheet 规范

所有动作资产统一输出为**单行横向精灵图（Horizontal Strip SpriteSheet）**：

```
+----------------+----------------+----------------+----------------+
|    Frame 0     |    Frame 1     |    Frame 2     |    Frame 3     |
| (64x80 待机基准) | (64x80 动画帧)  | (64x80 动画帧)  | (64x80 动画帧)  |
+----------------+----------------+----------------+----------------+
 <────────────────────── 总宽度 = 64px × 帧数 ──────────────────────>
```

### 5.1 核心动作集规划

| 动作标识 | 帧数 | 循环模式 | 周期/速率 | 动作特征与微动细节 |
|---|:---:|:---:|:---:|---|
| **`idle`**<br>(待机呼吸) | 4 帧 | 循环 | 1.2s<br>`steps(4)` | **同源微呼吸原则**：以 Frame 0 为母本，躯干胸口做 1px 起伏，呆毛迟滞半拍微晃 1px，发梢微动。每 2~3 个周期穿插 1 帧眨眼闭合，**相邻帧像素差异严格控制在 2%（20~30 像素以内）**，严禁全身剧烈位移。 |
| **`walk`**<br>(桌面漫步) | 4 帧 | 循环 | 0.8s<br>`steps(4)` | **反相交替真实步态**：双腿严格反向交替迈出小内八碎步（左脚前探 $\to$ 居中落地支撑 $\to$ 右脚前探 $\to$ 居中落地支撑）。支撑脚贴地补偿，发簇与双手前后微幅摆动。严禁单腿拖地瘸拐。 |
| **`poked`**<br>(受戳交互) | 3 帧 | 单次 | 0.45s | **生动受惊反馈**：<br>· F0：待机基准；<br>· F1：身体因受戳微微缩脖/下压 1px，眼睛闭合成可爱紧闭弧线，呆毛蓄力下压；<br>· F2：呆毛如弹簧般向上反弹拉伸 2px，双眼睁开水润带光，随后平滑复原至 F0。 |
| **`dragged`**<br>(提空抓起) | 2 帧 | 循环 | 0.5s | 角色被鼠标提起悬空，双脚在空中微弱无辜扑腾，两手微微张开，呆毛向上飘起。 |
| **`sit`**<br>(疲惫歇息) | 2 帧 | 循环 | 1.6s | 活力值低下时触发：整只抱膝坐于地面，小内八脚尖并拢，小脸微埋，呆毛微耷。 |
| **`sleep`**<br>(熟睡团子) | 4 帧 | 循环 | 2.4s | 深夜或极度疲劳：整个人缩成圆滚滚毛球团子，发尾如蚕茧包裹身体，呼吸极轻微，头顶冒出像素 `z..Z`。 |

## 六、分层纸娃娃（衣柜系统）拆件要求

桌宠支持换装系统，所有可拆卸服饰必须遵循**母本原位拆件法则**：

```
                      【顶层】Hair_Front / Bow / Acc (发夹、前发呆毛)
                                 ▲
                      【上层】Outfit (抹胸、上衣、外套、配饰)
                                 ▲
                      【中层】Bottoms (短裤、裙子、鞋袜)
                                 ▲
                      【基座】Base 素体 (完整脸型、五官、泪痣、裸体躯干与四肢)
                                 ▲
                      【底层】Hair_Back (后景瀑布长发)
```

### 6.1 拆件制作铁律
1. **唯一母本真理原点**：所有散件图层必须在统一的 64×80 画布母本坐标下绘制与擦除导出，保留天然透明占位，叠合时自动 $100\%$ 服帖，严禁使用偏移算法进行后期拼贴。
2. **基座图层纯洁性（P0 级防护）**：
   - 分层纸娃娃模式下，基座层 `[data-slot="base"]` **只承载纯净裸素体步态**。
   - 严禁将穿有完整默认衣服的合成帧塞入基座层（防止玩家脱掉衣服走动时发生“默认衣服幽灵复活”的恶性穿模）。
3. **面部镂空守恒**：前发与帽子图层，在面部五官与眼下泪痣区域必须做 $100\%$ 干净镂空，严禁遮挡底图神髓。
4. **布料褶皱与厚度**：衣物切片严禁纯平色块贴图，必须附带领口缝线、边缘高光、布料阴影与外轮廓包边。

## 七、血泪经验与反模式负面清单（绝对禁止项）

为确保美术产出的高水准，彻底杜绝历史翻车事故，特列出以下**六大绝对红线**：

```
       ❌ 严禁几何函数代码代笔         ❌ 严禁粗糙降采样色块暴力替换
   (杜绝方块人、乐高积木、火柴人)    (杜绝毛毛虫一字浓眉、小腿条形码、脏噪点)
                    \                        /
                     \                      /
                      【美术产出六大高压红线】
                     /                      \
                    /                        \
       ❌ 严禁半透明杂边与羽化         ❌ 严禁非整数倍缩放与单腿瘸拐步态
   (杜绝黑边、白光晕、桌面毛刺)      (杜绝长短腿走样、单腿拖地悬空假走动)
```

### 7.1 绝对禁止清单
1. **严禁程序员用代码几何函数凭空绘制二次元角色（“抽象几何人”惨案）**：
   - 严禁用 `draw.rectangle`、`draw.ellipse` 等代码函数拼凑脸型五官与躯干。
   - 算法与脚本仅允许用于调色板量化、切片校验、最近邻导出与自动化门禁，角色美术必须由原画雕琢或高水准点阵手绘产出。
2. **严禁粗暴下采样后进行全局色值盲目替换（“脏色泄露”惨案）**：
   - 杜绝在模糊降采样图上批量将暗色替换为纯黑，否则睫毛会连成粗重毛毛虫一字眉、小腿肚会出现竖向条形码脏纹、发丝会洒满泥斑状噪点。
3. **严禁 Alpha 半透明边缘（“桌面黑眼圈与白光晕”惨案）**：
   - 严禁导出带抗锯齿羽化半透明（$\alpha \in [1, 254]$）的 PNG。桌面无边框透明窗口渲染半透明边缘时，会在桌面背景上渲染出肮脏的黑边毛刺或白霜。
4. **严禁非整数倍拉伸缩放（“点阵长短腿走样”惨案）**：
   - 在前端渲染或窗口缩放中，像素画必须严格按照 $1\text{x}(64\text{px}) \to 2\text{x}(128\text{px}) \to 4\text{x}(256\text{px})$ 整数倍缩放，严禁 $1.5\text{x}(96\text{px})$ 等破坏点阵正方形比例的操作。
5. **严禁单腿拖地的瘸拐假步态**：
   - 动画帧不能仅摆动头发而双腿静态滑动，必须严格反相迈腿并有支撑着地补偿。
6. **严禁待机帧全躯干大位移闪烁**：
   - 呼吸帧像素差值超标会导致初澜宛如触电抽搐，必须严守 $<2\%$ 微呼吸原则。

### 8.3 终审人工肉眼质检铁律（终极把关）
> **“机器 11 门禁全 PASS 仅代表无语法错误，绝不等于二次元美术合格！”**

每次产出必须生成 **4x（256×320）与 8x（512×640）预览放大图**，由人工（或多重视角肉眼视觉复核）对照以下 5 问逐项确认：
1. **看脸**：双眼是否水灵灵且带有压实眼睑？有无变成死瞪眼或毛毛虫一字眉？
2. **看痣**：右眼下方 1px 泪痣是否清晰独立？与眼下沿有无留足肉色间隔？
3. **看发**：呆毛根部是否扎实？发尾冰蓝阶跳是否自然清透？外轮廓是否柔顺而不僵硬？
4. **看腿**：大腿是否圆润可爱？膝盖有无内收与粉晕高光？足尖小内八是否自然？
5. **看衣**：黑蝴蝶结与项圈是否层次分明？抹胸上缘有无立体阴影浮凸感？
