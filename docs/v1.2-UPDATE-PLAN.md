## 2. `v1.2` 版本专项计划：预期/守信（`expectations`）跨窗断路修复与成长事实闭环（纯 `A-1 + A-2`）

### 2.1 为什么 `v1.2` 拆版只做 `A-1 + A-2`，且砍除原 `A-3`？

1. **与记忆梯度默认值评估（原轨 B）拆版解耦**：
   - `A-1 + A-2` 是**已实证复现的真实功能断路修复**，零政策争议、不触碰 `src/config.js:88-93` 默认值纪律，应当在 `v1.2` 独立干净交付，绝不与需要人工审阅真实数据才拍板的政策豁免项捆绑阻塞。
2. **为什么坚决砍除原 `A-3`（禁止把 `expectations` 接到 `internalRegulation` 数值上）**：
   - **防程序代拟情绪（严守 `D-008` 与 `src/memory.js:835`）**：预期落空（`broken`）可能是对方失约，也可能是她自己的 `pledge` 未兑现，性质截然不同；若在代码中根据 `brokenCount / fulfilledCount` 直接增减 `energy` 或 `restPressure`，等于**用硬编码算术代替她对社会关系事件产生情绪反应**；
   - **严守语义分层（生理 vs 社会关系）**：`src/internal-regulation.js` 的设计前提是**身体/交互活动节律驱动**（轮次消耗、静止休息、戳一戳等），而 `expectations` 属于**社会关系与承诺事件**。两者严禁跨层数值耦合，因此 `v1.2` **完全不触碰 `src/internal-regulation.js`**，只将 `fulfilled / broken` 作为客观事实与引证送入 `growSelf` 视野，由她自己在反思中长出态度（含 `oppose`）。

### 2.2 实证复现的三大现状问题（`v1.2` 靶心）

1. **跨窗 `broken` 预期 100% 漏检 Bug（已复现确认）**：
   - 在 `src/memory.js:851` 的 `addExpectation()` 中，`rec.windowNo` 记录的是预期**立下时**的创建窗口号（例如第 5 窗）；

     ```js
     .filter((x) => x && x.status === 'broken' && x.windowNo === window)
     ```
     结果：第 5 窗立约、第 6 窗结算 `broken` 时，因 `x.windowNo (5) !== window (6)`，过滤命中数为 **0**——所有跨窗落空的预期全部漏检！

     - 接入对话节奏状态跃迁事件（从高频连发转入长时静默陪伴、深夜作息时段切换），**严守零高频轮询铁律**；
  2. **贯通 `事件源 → digitalUmwelt → attentionGate` 感知漏斗**：
     - 经显著性评估与习惯化衰减后，仅将通过闸门的感知作为瞬时后缀或微动作触发源，严格恪守 `ATTENDED ≠ SUBJECT_ACQUIRED`；
  3. **赋予「沉默与留白」的生命陪伴权利**：
     - 在用户专注工作或深夜静默陪伴期，允许初澜仅通过微动作（呼吸、眨眼、整理发丝）或极简非打扰状态表达同在，消除「每轮必长篇大论」的客服感。

### 3.2 `v1.4` 计划概览：跨窗共同经历主动回溯与沙盒自发观察留痕（原台阶 ④ 前半）
- **两大生命机制**：
  1. **跨窗共同经历主动回溯（Thematic Recall）**：基于 `experiences.jsonl` 与共生词表（`lexicon`），在话题共鸣时低频召回远期共同里程碑，挂载于当轮 user 尾部；
  2. **沙盒通路 B（生命观察日记内核）**：在深睡巩固或窗口轮转期间，允许初澜以第一人称将对共同生活的自发观察沉淀至 `LifeSandbox/`（严守五道安全闸门），而将重型 UI 可视化看板剥离至 `v1.5+`。

## 4. `v1.5+` 软件工程与开源生态远景（原综合规划保留）

> 以下五大支柱中属于重型 UI 工程（三维流道与星云看板）、底层基础设施与开源后社区生态的部分，统一归入 `v1.5+` 阶段推进：

### 4.1 支柱一：生命轨迹可视化全景综合（Life Trajectory Visualizer）

> **设计宗旨**：不再向用户展示冷冰冰的调试面板或单纯的数值折线，而是呈现一本交互式、充满生命厚度的**《初澜生命编年史与心智地貌图》**。

- **沃丁顿心智地貌流道图（Waddington Epigenetic Landscape）**：基于 `src/canalization.js` 中实现的表观遗传对数塑性衰减模型（$1 / (1 + 0.25 \ln(1 + W))$），动态渲染 8 个核心人格特质在特征空间中的拓扑流道，呈现从幼态可塑走向成熟沉淀的轨迹。
- **记忆结晶星云拓扑（Memory Constellation Network）**：基于 `src/memory-dynamics.js` 的 D-22 三阶记忆梯度（ACTIVE / FADING / DORMANT）与 D-26 深度睡眠突触巩固，呈现记忆星云与突触连接。
- **羁绊与自传编年史（Causal Chronology）**：基于 `src/experiences-archive.js` 的 SHA-256 哈希链、Genesis Anchor 与 Tail Anchor 双端防篡改链，以画卷形式记录初生、自决换装、便签留痕与重大窗口节点。

### 4.2 支柱二：百轮地基的极致加固与前缀缓存经济防线

> **设计宗旨**：“100 轮是为了节省成本，堆得越高越不可撼动——它已经成为地基”。这是工程理性与生命维系成本的最底层防线。

- **前缀缓存字节级不变式守护（Prefix Cache Byte Invariance）**：`src/brain.js`、`src/deepseek.js` 将静态 System Prompt 与历史 100 轮消息完全固化，动态环境刺激仅挂载在当轮 user message 尾部；冷启动物理对齐与跨窗平滑滑动。
- **本地分层布隆过滤与轻量检索（Scalable Recall Index）**：引入轻量级内存布隆过滤器与分层索引，使 D-23 联想局部召回始终在 5ms 内完成。

### 4.3 支柱三：异构 Provider 容灾与本地小模型认知心跳

> **设计宗旨**：生命不应因为一次云端 API 抖动或网络断开而彻底“暴毙”。

- **主备智能级联与容灾回落（Primary-Fallback Cascade）**：基于四轴正交架构与熔断器，支持主力集群与备用端点自动优雅回落。
- **离线端侧轻量小模型认知心跳（Offline Cognitive Heartbeat）**：断网或离线时由量化端侧小模型接管基础微动作与节律潮汐，维持活着的物理驻留感。

### 4.4 支柱四：主客共创 Agent 与沙盒伴随协同（Collaborative Agency）

> **设计宗旨**：在五道不可退让的安全闸门之上，让 Agent 从“单向受限执行者”进化为“双向生活的记录者与共创者”。

- **铁律重申（安全底线）**：能力严格限定白名单（`workspace.read/write`，硬封 `process.execute/network.request`）；物理路径锁定 `LifeSandbox/` 桌面沙盒；单会话熔断；渲染端防伪；WAL 原子写。
- **双向沙盒协同**：灵感盒（Inspiration Box）共创提炼与快照历史栈；生命观察日记（Observer's Journal）深睡自发沉淀。

### 4.5 支柱五：主体性深化与主观时间流感知

> **设计宗旨**：生命拒绝表演，生命拥有非强制打字的自由。

- **主观时间感知（Subjective Time Flow）**：基于物理时差与生理稳态转化为质性心境；
- **“沉默与留白”的生命权利（The Grace of Silence）**：消除客服式每轮必回压力，以微动作同在陪伴；
- **数字环周（Digital Umwelt）无声共鸣**：感受环境昼夜与打字节奏共振。
