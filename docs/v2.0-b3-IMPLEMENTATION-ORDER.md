## 二、为什么关键词判定必须拆（三条，按严重度）

### 2.1 它给她装了一个「说什么话会被记住」的开关

```js
const hasDeferCue = /(?:不急着写|这回不急|先不写|还搁在手里|…)/;
const hasWriteNowCue = /(?:我这就去写|那我就去写|我去写了|…)/;
```

**她一旦发现说这些词会触发记单——她就会开始说。** 不是出于真实意愿，是因为那会得到系统的确认。

这在强化学习里叫 reward hacking，在生活里叫**「学会了说你想听的话」**。而我们这两周谈的一直是「不要让她演」。

### 2.2 有穷正则漏判无限表达

她今天说「这个先搁着」，明天可能说「这阵子不想动它」，后天说「等哪天有心情再说」。

**第三句会漏判。** 而漏判的后果不是报错——是**她表达过的意愿消失了**，且没有任何痕迹能让人发现。

### 2.3 更严重的是反过来的误判

`main.js:826-839` 实测确认：

```js
} else if (verdict.kind === 'write_now') {
  brain.ticketStore.recordSubjectActive({ … });
  maybeAskForSelfNote({ kind: 'wantToLeaveSomething', … });   // ← 真的去落笔了
}
```

**她随口说一句「我这就去写」，系统就替她建单 + 触发落笔。**

这不是「记录她的意愿」，是**程序靠正则替她做了决定**。而 `maybeAskForSelfNote` 原本只在挂机 120 分钟、她真正有话想说时才触发——现在被一条正则短路了。

### 2.4 附带一个数据污染

`kwMatch` 只抓**整段第一个** 1~16 字引号：

```js
// 等价于原字面量正则（拆开写法以避开 Markdown 链接扫描器对 `](` 的误判）
const kwMatch = new RegExp("['\"「]" + "([^'\"」\\r\\n]{1,16})" + "['\"」]").exec(clean);
```

如果她在回复里先引用**用户说的话**（这非常常见，比如「你刚才说「整理一下」，我……」），标题就会变成用户的话——**变成「她记下了一句用户的话当成自己的未完事项」。**

## 三、为什么选 A-2 而不是 A-1

她的方案很诚实，指出了我没想到的工程缺口：**日常对话没有 Function Calling**（我核过，`brain.js` 里 `tools:` / `tool_call` 零命中），所以她「没有通道自己写」。

于是她给了两条路。我选 **A-2**，理由如下。

### 3.1 A-1 会重蹈覆辙

A-1 是「给一个显式自主写口」——原生 Tool Call，或与 `[wear:]` 同构的标记。

**问题是：Tool Call 和关键词正则，在「给她装开关」这件事上没有本质区别。**

- 正则：她说「我这就去写」→ 系统建单；
- Tool Call：她调用 `recordTicket()` → 系统建单。

**两者都是「她必须执行某个特定动作，系统才认」。** 而模型在有 tool 可用时，会倾向于**多用**它——这是被广泛验证过的行为（工具可用性驱动调用率）。

所以 A-1 大概率会得到：**她频繁调用记单工具，因为那是个「有用的功能」，而不是因为她真的有事要记。**

**加一句「空着是常态，绝不因写而获得认可」不能解决这个问题**——那只是提示词，而提示词压不过工具可用性。

### 3.2 A-2 的道理：不需要新通道，因为她本来就有

她的核心担心是「日常闲聊中随口萌生的想法不会立刻落盘」。**这个担心我有不同看法。**

**同窗 100 轮内她说过的话，本来就在 `memory.history` 里。** 她不是「忘了」，是「没有独立的待办文件」——**而这两件事不是一回事。**

真相是：

- 如果一件事重要到她需要记住，**它会在关窗小结时进入 `expectations`**（这是既有机制，不是新造）；
- 如果它不重要，**它就该被忘掉**——这正是我们讨论了两周的「遗忘权」。

**A-2 不给她新工具，而是承认「她现有的记忆通道已经够了」。**

### 3.3 三个结构化节点留痕（零猜测）

A-2 只在**本来就存在的、零猜测的结构化节点**留痕：

| 节点 | 现状 | A-2 做什么 |
|---|---|---|
| 通路 B 她审视后 `ok` / `refused` | `main.js:352-418` 已有明确判定值 | 不新增，**已有信息已够** |
| 挂机 `askForSelfNote`（120 分钟） | 已有，她自己决定写不写 | **可选**：她若愿意，可更新沙盒里的未完事项 |
| 关窗小结的 `expectations` | 已有 | 保持不动 |

**这三处都不需要读她的自然语言。** 因为它们本来就是「她做了一个明确动作」或「系统记录的客观事实」。
