**改动 2：护栏逻辑**（`src/brain.js:2823-2824`）

```js
// 修改前：
// 判据 2：篇幅护栏。不得少于 30 字，不得超过 400 字
if (text.length < 30 || text.length > 400) return null;

// 修改后：
// 判据 2：篇幅护栏。
//   · 过短（< 30 字）丢弃 —— 那是没写出东西，不是日记
//   · 过长不丢弃，改为句界截断保留 —— 她真诚写了 450 字却整篇扔掉，
//     比截断更糟（且完全静默，日志里看不出她写过）。
//   · 复用 v1.2.x 的 truncateFadingText，不另写第二套截断逻辑。
if (text.length < 30) return null;
const finalContent = text.length > 400 ? truncateFadingText(text, 400) : text;
```

并把函数末尾的 `return { content: text, ... }` 改为 `return { content: finalContent, ... }`。

## 6. 🔴 施工前必读：对本文档的三处修正（DSH 复核后追加）

反重力的施工理解正确，但有**三处它没意识到**的问题。以下修正**以本节为准**。

### 修正 1：现有断言 251 行必须改写，否则新代码必红

`test/v14-observer-journal.test.js:251` 现在是：

```js
// 篇幅护栏：超长（>400 字符）返回 null
const tooLong = '字'.repeat(401);
b.api = { complete: async () => ({ text: tooLong, usage: null }) };
check('超过 400 字符篇幅护栏返回 null', (await b.askForObserverJournal({})) === null);
```

**这条断言锁定的正是本次要改的行为。** 改完代码它必然 FAIL。

**它不是该删的断言，而是必须改写语义** —— 保护旧行为的断言悄悄删掉，等于丢保护：

```js
// 篇幅护栏：超长（>400 字符）【句界截断保留，不再整篇丢弃】(v1.6-a)
const tooLong = '字'.repeat(500);   // 无标点，走回退路径
b.api = { complete: async () => ({ text: tooLong, usage: null }) };
const longRes = await b.askForObserverJournal({});
check('v1.6-a: 超长日记不再返回 null（改为截断保留）', longRes !== null);
check('v1.6-a: 超长日记长度上界 <= 403（400 + 省略号）',
  longRes && longRes.content.length <= 403, longRes ? 'len=' + longRes.content.length : 'null');
check('v1.6-a: 无标点超长串严格回退为 slice(0,400) + "..."',
  longRes && longRes.content === tooLong.slice(0, 400) + '...');
```

### 修正 2：句界截断的断言必须验证「结尾是标点」

实测 `truncateFadingText('今天你一直在改那段代码，眉头皱着。'.repeat(30), 400)`：

```text
输入 510 字 -> 输出 394 字，结尾 。...
```

**这是 v1.6-a 的核心判别力**。断言：

```js
const punctText = '今天你一直在改那段代码，眉头皱着。'.repeat(30);  // 510 字
b.api = { complete: async () => ({ text: punctText, usage: null }) };
const punctRes = await b.askForObserverJournal({});
check('v1.6-a: 带标点超长串在句界处截断（结尾为标点+省略号）',
  punctRes && /[。；！？]\.\.\.$/.test(punctRes.content),
  punctRes ? JSON.stringify(punctRes.content.slice(-6)) : 'null');
```

🔴 若把 `truncateFadingText` 换成裸 `slice`，**这条必 FAIL**。

### 修正 3：不是「追加 4 条」，而是「改写 1 条 + 新增 2 条」

| 动作 | 断言 |
