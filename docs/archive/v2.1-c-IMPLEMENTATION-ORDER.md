## 一、目标与核心边界

### 1.1 `v2.1-c` 认知张力闭环

1. **只读三源输入**（零 LLM 调用、零自然语言正则、零 90s 扫盘）：
   - `ledgerMaxPressure`：来自 `selfLedger.getRevisionTensionSummary().maxPressure`（`v2.1-b`）；
   - `reunionSurprise`：来自 `internalRegulation.getAllostasisSummary().lastSurprise`（`v2.1-a`，仅正向误差 `> 0` 贡献张力）；
   - `lastWindowTension`：来自关窗完成时计算的当窗 `arousalTrajectory` / 认知冲突张力 `[0, 1]`，随 `internal-regulation.json` 持久化防重启归零。
2. **门槛调制红线**：
   - 外层 `idleNeed`、`COOLDOWN_MS`（45s）、`CURIOSITY_THROTTLE_MS`（40min）、`spokenDuringIdle`、`selfNoteDuringIdle` 与 `sleepMode` **一毫秒不动**；
   - `SELF_NOTE_IDLE_MS`（默认 120min）：在 `[0.8, 1.2]` 区间双向调节（高张力最低 96min，低张力最高 144min，始终大于外层 30min `idleNeed`）；
   - `CURIOSITY_IDLE_MS`（默认 30min）：高张力维持 30min（绝不突破外层 `idleNeed`），低张力（`tension < 0.5`）温和拉长至最高 36min（`×1.2`），体现平静时更安于沉默。
   - `baseline` 模式下 `computeEpistemicTension()` 恒返回 `0`，或未传 `epistemicTension` 时保持原生常量行为。

### 1.2 `v2.1-d` 记忆再巩固只读观测埋点

1. **日志落点隔离**：`agent-observations.jsonl` 专供 Agent 观察档使用；再巩固埋点走 `brain.appendTelemetry({ recordType: 'reconsolidation_candidate_observed', ... })` 落入 `experiment-telemetry.jsonl`，**且必须在 `appendTelemetry()` 内显式放行 `traceId / sourceWindowNo / reactivatedWindowNo / prevTier` 四个字段**（源码实勘确认 `appendTelemetry()` 按 `recordType` 白名单挑字段）。
2. **`baseline` 与 `proactive` 隔离**：仅在 `!proactive` 且 `this.cfg.experimentMode !== 'baseline'` 时记录；`memory-dynamics.js` 的 `reactivate()` 刻意不改 `trace.tier`，返回值中的 `tier` 即为 `prevTier`，仅 `prevTier === 'FADING' || prevTier === 'DORMANT'` 时落盘。
