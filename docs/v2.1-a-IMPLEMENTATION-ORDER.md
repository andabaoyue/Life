## 一、目标与核心边界

### 1.1 要解决的问题

当前 `src/reunion.js` 使用固定常数 `REUNION_MIN_MS = 6 * 3600 * 1000` 判定重逢文案，而 `src/internal-regulation.js` 的 `updateOnInteractionTurn()` 仅对单次交互做机械加减，缺乏「本次离开偏离你们惯常相处节奏多远」的先验度量。

本单新增 `AllostasisPrior`（关系节奏先验）：

- 基于历史真实跨会话间隔（`>= 30min`）的对数空间中位数与 MAD（中位绝对偏差）计算当前关系的习惯节律 `typicalGapMs` 与归一化预测误差 `gapSurprise ∈ [-2, 3]`；
- 仅在样本数 `>= 3`（`priorReady === true`）且发生跨段重连时，向 `InternalRegulationManager` 注入温和的预测误差调节。

### 1.2 六条硬边界（不可退让）

1. **绝不修改 `src/reunion.js`**：保留 `REUNION_MIN_MS = 6h`、客观时长文案与 `test/v18-reunion.test.js` 全量 53 项契约，不推断用户作息。
2. **绝不挂进 `takeReunionNote()`**：实勘确认 `brain.ask(..., { proactive: true })` 同样走 `memory.build()` → `takeReunionNote()`，且 `currentSelfContext()` 在 `memory.build()` 之前执行。本单接线点**必须落在 `brain.ask` 的 `if (this.internalRegulation && !proactive)` 分支内、`currentSelfContext()` 之前**，保证主动搭话不污染先验、且当轮体感无一轮错位。
3. **独立起点 `lastUserTurnAt`**：不复用 `stats.lastSeenAt`（会被 `activity` IPC 刷新）或 `internalRegulation.updatedAt`（会被戳/拖/入睡刷新）。忽略时钟回拨（`awayMs <= 0`），对超过 30 天的极端长间隔做 Winsorize 上界截断，且坚持**先算后入队**。
4. **不直接覆写 `salienceThreshold`**：该字段在每次 turn/activity 都会由 `_computeSalienceThreshold(arousal)` 重算；正预测误差（`gapSurprise >= 1.2`）仅温和抬升 `arousal`（`+4 ~ +8`）实现间接联动；负预测误差（`gapSurprise <= -1.0`）调节 `moodWarmth`（`+2 ~ +4`）前**必须先调 `_decayMood(at)`**。
5. **严格基线与消融隔离（D-009）**：`experimentMode === 'baseline'`、`internalRegulation: false` 或 `allostasisPrior: false` 时，100% 旁路零副作用，且不加载/污染基线状态；`config.js` 的 `DEFAULTS.experimentModules` 与 `sanitize()` 白名单同步登记 `allostasisPrior`。
6. **前缀缓存纯洁性与零裸标量泄露（D-008）**：绝不碰 `systemText()`，绝不向模型暴露 `gapSurprise` / `typicalGapMs` 等内部数值。
